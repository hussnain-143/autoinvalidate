# 🌐 `autoinvalidate` Web Docs & Simulator

The official documentation website and interactive SQL cache simulator for [`autoinvalidate`](https://github.com/hussnain-143/autoinvalidate).

Built with **Next.js 15 App Router**, strict TypeScript, and a high-performance in-browser SQL AST analyzer.

---

## 🚀 Running Locally

```bash
# From repository root:
npm run dev:web

# Or from inside apps/web:
cd apps/web
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the documentation and interactive simulator.

---

## 🏗️ Production Build

```bash
npm run build:web
```

---

## 🚀 One-Click Deploy to Vercel

This Next.js site is ready for zero-configuration deployment to [Vercel](https://vercel.com):
1. Import repository `hussnain-143/autoinvalidate`.
2. Set **Root Directory** to `apps/web`.
3. Deploy!
